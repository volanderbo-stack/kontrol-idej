# Контроль ідей

PWA-застосунок, який зберігає мої проєкти, пропонує ідеї на їх основі (об'єднання → покращення → нове) і відсіює слабкі через фільтр «Чи дійсно потрібно?». Одночасно в роботі — не більше 3 проєктів.

- Один `index.html` (HTML + CSS + JS), без сервера, дані в `localStorage`.
- Офлайн через `sw.js`, можна додати на головний екран.
- Деплой: push у `main` → workflow копіює файли в гілку `gh-pages` → GitHub Pages.

Після зміни файлів збільш версію `CACHE` у `sw.js`, щоб телефон підтягнув оновлення.

Локально: `python -m http.server 8765` і відкрити http://localhost:8765
